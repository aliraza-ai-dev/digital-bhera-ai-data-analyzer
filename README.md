# Digital Bhera AI Data Analyzer

A futuristic AI-powered web application by **Digital Bhera by Ali Raza** that allows users to upload CSV files and instantly get:

- Dataset preview
- Missing value analysis
- Numeric statistics
- Categorical summaries
- Histogram charts
- Correlation heatmaps
- AI-style insights

## Tech Stack

- Python
- FastAPI
- Pandas
- Matplotlib
- Seaborn
- HTML
- CSS
- Jinja2

## Run Locally

```bash
pip install -r requirements.txt
uvicorn app:app --reload
